# 🎨 Design Guidelines – Application Planning Premium

## 🎯 Identité & Vision

- **Cible** : Cadres, dirigeants de PME, responsables qui gèrent eux-mêmes leurs plannings.
- **Émotion recherchée** : Luxe, confiance, premium minimaliste.
- **Références** : Apple (sobriété, finesse), Tesla (effet haut de gamme et moderne).

---

## 🎨 Palette de Couleurs

- **Couleur principale (fond)** : Bleu nuit foncé `#0A1A2F`
- **Couleur secondaire (accent)** : Jaune padel adouci `#F2E94E`
- **Couleur tertiaire (neutre)** : Blanc pur `#FFFFFF`
- **Couleur complémentaire (pastel)** : Vert pastel `#A8E6CF`

---

## 🔤 Typographie

- **Police recommandée** : Inter ou SF Pro (sobre, moderne, premium).
- **Titres (H1/H2)** : gras, espacés, taille impactante (28–36px).
- **Texte courant** : lisible, taille confortable (16–18px).
- **Accentuation** : utiliser le jaune uniquement pour CTA et mots-clés importants.

---

## 🖼️ UI Components

### Boutons

- Forme : arrondis doux (radius 12–16px).
- Hover : légère élévation (shadow + translation Y de -2px).
- Style :
  - Normal → fond bleu nuit, texte blanc.
  - Hover → fond jaune, texte bleu nuit.

### Cards / Conteneurs

- Style Apple → arrondis généreux (20–30px).
- Légère ombre subtile pour donner un effet flottant.
- Fond blanc avec accents pastel/bleu nuit.

### Inputs / Formulaires

- Bord arrondi.
- Shadow subtile sur le focus.
- Labels sobres et minimalistes.

---

## ✨ Effets & Animations

- Micro-animations fluides :
  - Hover sur boutons et liens.
  - Sidebar rétractable avec transition douce (ease-in-out 300ms).
  - Scroll fluide entre sections.
- Pas d’animations lourdes → priorité à la rapidité et simplicité.

---

## 📱 UX & Navigation

- **Sidebar rétractable** (ouverte par défaut, possibilité de compacter en icônes).
- Maximum **3 clics pour atteindre une fonctionnalité clé**.
- **Accueil** : sobre, hero minimaliste avec slogan + CTA direct (ex : “Créer un planning”).
- Navigation intuitive :
  - Sidebar fixe pour l’essentiel.
  - Icônes + labels pour faciliter la compréhension.
- Pas de Dark mode → un seul thème premium.

---

✅ Ce document sert de **base de design system** pour les développeurs et designers.  
Toutes les décisions de design doivent respecter ces lignes directrices afin d’assurer **cohérence, premium look & UX optimale**.
